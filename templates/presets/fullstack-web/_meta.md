## Best Suited For
- React + Node.js fullstack web applications
- Projects needing clear frontend/backend separation
- Teams requiring structured orchestration with reporting lines
- Medium to large projects with 4+ team members

## Assumed Tech Stack
- Frontend: React, TypeScript, Tailwind CSS, Vite/Next.js
- Backend: Node.js, Express/Fastify, PostgreSQL, Prisma
- Testing: Jest/Vitest, Storybook, Playwright
- Infrastructure: Docker, GitHub Actions
